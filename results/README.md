# results: Deterministic Benchmark Outputs and Empirical Evidence

## Abstract

Scientific reproducibility requires that benchmark results, timing profiles, and error metrics be verifiable and inspectable in their raw form. This directory contains the authoritative evaluation outputs generated by VoiceHCI-Bench across 182 test interactions.

All results stored here are generated deterministically using synthetic speech recognition streams controlled by `FakeClock` with CRC32-seeded jitter.

---

## 1. Output Artifacts

- **`REPORT.md`**: Human-readable markdown summary report generated directly from raw benchmark data. Displays performance tables for dictation and action systems, category heatmaps, and metric definitions.
- **`latest.json`**: Machine-readable JSON payload containing complete execution traces, system configurations, per-record outputs, and timing quantiles.

## 3. Regenerating Benchmark Artifacts

To re-run the benchmark and update `latest.json` and `REPORT.md`:

```bash
python -m voicehci_bench.cli run
```

To run a targeted comparison of specific candidate systems:

```bash
python -m voicehci_bench.cli run --systems thought-stream,verbatim-stream,final-cleaned
```
